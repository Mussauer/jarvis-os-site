Política de privacidade · JARVIS OS

Atualizada em 8 de novembro de 2026.

JARVIS OS é um assistente pessoal de uso privado de João Mussauer, que roda no computador do próprio dono.

  • Quem usa: somente o dono. Não há outros usuários.
  • O que acessa: com a autorização do dono, os arquivos do Google Drive dele, para ler, criar e organizar documentos e pastas. O JARVIS OS não exclui arquivos.
  • Onde ficam os dados: no computador do dono. As credenciais de acesso ficam guardadas localmente e não são publicadas.
  • Compartilhamento: nenhum dado é vendido, compartilhado ou usado para publicidade. O uso dos dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
  • Como revogar: a qualquer momento em myaccount.google.com/permissions.
